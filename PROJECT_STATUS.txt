1. LANCER L'APPLICATION
   └─ Commande : npm start
   └─ Scanner le QR code avec Expo Go

2. CRÉER UN COMPTE
   └─ Ouvrir l'app
   └─ Cliquer sur "Créer un compte"
   └─ Remplir le formulaire

3. AJOUTER DES PARCELLES DE TEST
   └─ Voir : src/utils/seed-data.sql
   └─ Remplacer USER_ID_HERE par votre ID
   └─ Exécuter dans SQL Editor Supabase

4. TESTER LES FONCTIONNALITÉS
   └─ Dashboard : Liste des parcelles
   └─ Carte : Visualisation géographique
   └─ Détails : Informations parcelle

5. CONFIGURER LE WORKFLOW MAKE (optionnel)
   └─ Voir : MAKE_WORKFLOW.md
   └─ Temps estimé : 20 minutes
